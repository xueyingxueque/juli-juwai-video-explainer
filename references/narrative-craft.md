## 1. 核心公式

```
黄金三秒钩子 + 密集情绪爆点 + 带情绪的口语化文案 + 固定人设记忆点
```

**解说不等于复述。** "同样一段剧情，平铺直叙和带情绪地说，效果差十倍。"

---

## 2. 开头：只有三种框架（90% 爆款在这三种里做微调）

| 框架 | 结构 | 实例 |
|---|---|---|
| **甩冲突** | 直接扔信息炸弹 | "新婚当晚，丈夫掀开盖头，发现新娘是自己的亲姐姐" |
| **倒叙钩子** | 先给结局，再说回三天前 | "事情要从三天前说起" |
| **身份反差** | 平凡外表 ↔ 隐藏身份 | "扫地阿姨其实是集团老板""落魄女婿是隐藏大佬" |

> **前 3 秒留存率决定后面做得再好也没用。**

### 时间轴结构（60–300 秒通用）

| 区间 | 作用 |
|---|---|
| 0-3s | 强钩子（情绪/场景/数据） |
| 4-15s | 价值承诺（"这集讲完…"） |
| 16-30s | 行为指令/互动引导 |
| 每 15-30s | **必须给一个刺激**：反转 / 打脸 / 新悬念 |

## 3. ★ 视角定死（本引擎最缺的，也是我这次稿子翻车的原因）

> 来源：《影视解说文案剪辑课》——"视角定死：从多人物中扣一个主角，所有其他人通过他引出。谁的画面多、画面好，优先参考。"

**错误示范**（视角乱跳）：
```
村民骂道士 → 道士不在乎 → 县太爷判案
```

**正确示范**：全员以道士视角推进。

**为什么这条是铁律**：我这次 S3 产出的稿子，通篇人称在"她/他"之间跳，
根因就是**视角没定死**——VLM 试图同时讲两个人的故事。

**引擎落地**（`s3_script.py` 必做）：
1. S2 解构阶段必须先确定 `POV`（主角是谁），写进 story.json。
2. S3 写稿前把 POV 作为硬约束注入提示词：**"全程只从主角一人视角推进，其他人一律通过主角引出"**。
3. 人物一致性门（`check_gender`）改为**以 POV 为准**：全篇人称必须与 POV 画面一致。

## 4. 剧情节奏：掐着爆点，不做流水账

| 要点 | 具体要求 |
|---|---|
| 爆点密度 | **每 30-60 秒一个情绪爆点**；2-3 分钟视频理想是每 20-30 秒一个 |
| 压缩过渡戏 | "能用一句话带过的绝不说三句" |
| 禁忌 | **每段平均用力**（观众看到一半划走） |

## 4.5 ★★ 八种衔接方法（解决「不像故事，像翻译画面」）

> 来源：《影视解说文案剪辑课》实操章节。这是本文件**最关键的一节**。
>
> 总纲原文：「段落与段落（事件与事件）之间必须强关联，用八种衔接方法保证故事不"断层"；
> **前 30 秒是命门，断则死**。」

### 前提：强关联是及格线，连得好是加分项

**常见断裂**：前面讲三个女孩被困，后面突然跳到"男人从小就是变态" → **死**。

**典型断裂的样子**（引擎实测产出，属"平铺"而非"叙事"）：
```
手术费十几万，我咬牙扛着，她还在说我不配当主厨    ← 突然跳到手术费，前句没铺垫
她哭着问我为什么还不低头，我只笑：你赢过我吗？    ← 独立感叹，与上下文无衔接
```

### 八种衔接法

| # | 方法 | 句式 / 例句 | 本质 |
|---|---|---|---|
| 1 | **递进连接** | "然而，仅仅是这样，可还没完"／"但更糟糕的是"／"但这还不够" | 上一层不够，下一层更猛 |
| 2 | **人物连接**（引导登场） | 正确：门突然开了 → 神秘男搬着凳子出现<br>错误：直接写"这时张三出现了" | 新人物引出新故事，越自然观众越不排斥 |
| 3 | **时间连接** | "第二天"／"下午时分"／"就在这时"／"隔天" | **最基础，单独用≈弱连接**；前 30 秒内断=判死刑 |
| 4 | **联系点连接** | "但真的假不了，假的真不了"<br>句式库：但…偏偏…／本以为…／没想到…／不料…／谁知…／不曾想… | 两个事件有共同点，连接就自然 |
| 5 | **因果连接** | "因为…所以…"（**最核心**） | 见 §4.6 |
| 6 | **反差连接** | "别人…而他…" | 用对比制造张力 |
| 7 | **悬念连接** | "可他万万没想到…" | 主动在节点处开缺口 |
| 8 | **画面承接** | 上一镜的物件/动作引出下一镜 | 声画配合 |

> ⚠️ **时间连接在前 30 秒要慎用**（"第二天""这时候"单独出现是弱连接）。
> 前 30 秒观众还没建立容忍度，必须用**因果/反差/联系点**这类强连接。

## 4.6 ★★ 拒绝复述画面（纪录片写作铁律，短剧同样适用）

> 来源：《学会这五点你就会写解说词了》。原文：
> **「这是新手最易踩坑的误区。优质解说词绝不重复镜头内容，
> 画面负责呈现视觉场景，解说负责解读深层内核。」**

**「画面见形，文字传意」**——镜头展示风景、人物动作、场景；
**解说补充画面没有的时间背景、因果逻辑、细节内涵与隐性情绪。**

| ❌ 翻译画面（就是在做这个） | ✅ 解读内核 |
|---|---|
| "她把辞职报告撕了" | "她把辞职报告撕了——那是他攒了三个月的尊严" |
| "他在工地上搬砖" | "他在工地上搬砖，一个月挣的还不够她买一个包" |
| "他获得金牌" | "金牌到手那天，她才知道自己嫁的是个什么人" |

### 重构叙事逻辑（原文第四点）

> 「普通文案以**时间**为线，记录事件始末；而解说词以**因果逻辑**为核心。
> 摒弃『先做什么、后做什么』的平铺叙事，重点挖掘事件背后的**动机、过程的难处、结局的意义**。」

**引擎落地**：`s3_script.py` 的提示词必须显式要求
**"用『因为…所以…』推动，禁止『接着…然后…』的平铺"**。

## 4.7 ★ 连环结构（因果链的密度要求）

> 来源：《如何用连环剧情介绍打造引人入胜的影视解说》
>
> 「人类大脑对**因果链**的敏感度远高于碎片信息……当观众接收到具有明确
> **"因—果—再因"**逻辑的连续事件序列时，注意力留存率较平铺直叙提升 3.2 倍。」

**关键指标：每环必须具备不可替代性——删去任一环，后续逻辑即断裂。**

**三幕压缩法**（短版 60–90 秒通稿，长版按段数放大）：

| 幕 | 时长 | 内容 |
|---|---|---|
| 首幕 | 15s | 核心冲突 + 人物反常态 |
| 中幕 | 45s | 三次递进式对抗（物理/心理/规则各一次） |
| 终幕 | 20s | 停驻于最具张力的**未解节点** |

**枢纽事件**：从原片全量中筛出 **3 个承上启下的事件**，每个用不超过 12 字动宾短语概括
（如"调换亲子鉴定样本""直播揭穿假慈善"）。

> **因此本引擎的正确做法**：
> 不是把 37 帧各写一句，而是**先筛 3 个枢纽事件，再展开因果**。
> 这正是当前 S2/S3 缺失的一环——`story.acts` 只有三段式，**没有事件链与枢纽筛选**。

## 4.8 悬念植入（在确定性陈述中埋不确定性）

> 「表面陈述事实却暗藏三重留白：人物动机未明、规则边界未显、代价尚未显现。」

示例：描述"主角签署保密协议"时，同步指出"第 7 条手写补充条款被墨水覆盖"
或"监控画面在签约前 11 秒突然黑屏 1.7 秒"。

> 这类细节**均来自原始影像可验证帧，非主观虚构**。
> 含 3 处以上可验证细节留白的解说，观众二次观看率提升至 74%
> ——因为触发"证据核查"行为，大脑自动回溯画面找线索。

可自动挖出「画面内文字/异常细节」作为留白点。

## 5. 文案三特征（高手共性）

| 特征 | 要求 |
|---|---|
| **口语化** | 像跟朋友聊天，多用短句，少用书面语 |
| **带态度** | 站观众这边：反派作恶就骂两句，主角逆袭就爽一把 |
| **留悬念** | 每段结束埋钩子，如"但他不知道的是，真正的危险才刚刚开始" |

## 6. 剪辑铁律（与写稿直接相关）

| 规则 | 原因 |
|---|---|
| **一句话配一个画面**，话没说完不跳 | 观众要跟得上 |
| 句子太长 → 做分句 | 配音与字幕都要用 |
| **画面太短配不上 → 就不写这段** | 1 秒镜头凑一句很难看 |
| 人物特写开头 → 后面必须紧跟具体动作 | 特写不带信息量 |
| 废镜头（笑/惊讶/乱入）→ 一律砍掉 | 拖节奏 |
| **别变速** | 丑 |
| 做竖版 9:16 | 横版画面缺太多，调起来费劲 |

> **对本引擎的直接约束**：`target_seconds` 之外，还要按**画面可用时长**决定写多少字。
> 画面撑不住的长镜头，不该写对应文案。

## 7. ★ 改写的"加减法"（低成本提升质量）

来源：《影视解说文案剪辑课》——"改字改句 + 每隔五六句做点小加法/小加法"。

**加法示例**（把平淡句变成有锋芒的句）：
```
原：这一刀下去，小伙定是必死无疑，县令看到这一幕吓得脸色发白
改：这一刀砍的不只是人命，更是他自己的脑袋乌纱帽
```

**减法示例**（砍掉过渡，两句直接接）：
```
原：捕快为了快点去死，竟然一刀斩了当朝丞相之子，这一刀下去，小伙定是必死无疑
改：（砍掉过渡画面）直接两句话接
```

**引擎落地**：
- S3 提示词要显式给出"加法/减法"示例，让模型学会把平淡句改出锋芒。

## 8. 三大误区（务必避免）

| 误区 | 后果 | 正解 |
|---|---|---|
| **贪多** | 2 分钟塞 5 集，哪个都没讲透 | 宁可信息量小，把一个反转讲清楚 |
| **只讲剧情不讲人** | 观众没有代入感 | 短剧追的是角色命运：**主角为什么隐忍、反派坏在哪** |
| **开头抄别人** | 平台打击同质化 | 钩子可借鉴框架，**具体表达必须换自己的** |

## 9. 人设记忆点（低成本建立辨识度）

> "同样题材的解说号一大堆，观众凭什么记住你？"

| 手法 | 说明 |
|---|---|
| 方言 | 地域腔 |
| 固定称呼 | 给主角/反派固定代称 |
| 口头禅 | 每期结尾同一句 |

**平台推荐机制吃这一套**——有辨识度的账号完播率与关注转化都更高。
