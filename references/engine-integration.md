## 0. 为什么需要这份

本引擎（`剧里剧外-视频解说引擎`）负责**素材 → 解说成片**这一段。
但它不是视频制作的终点——成片之后还有精剪、包装、片头片尾、多片合并、封面等。

这些能力**不要在本引擎里重复实现**，转交给对应引擎：

> **缺什么补什么，缺什么交什么，不自己造轮子。**

## 2. 上游：配音（已实现）

### 调用方式

`build.py` 的 `narrate()` 直接以子进程调：

```python
DUB_PY = r'D:\AITools\TTS\Dots.tts\wzf\python.exe'
DUB = r'C:/Users/Administrator/.workbuddy/skills/本地配音工坊/dub.py'

sh([DUB_PY, '-X', 'utf8', DUB, '--voice', voice,
    '--text', text, '--out', out], 900)
```

### 契约

| 项 | 值 |
|---|---|
| 输入 | 单段解说词 `text` + 音色 `voice` |
| 输出 | `speech/seg{k}.wav`（单声道 44100） |
| 音色 | ★ **必填，无默认值**。缺省且 plan 无 `voice` → **报错退出**（禁无脑默认音色）。三级决策见 SKILL.md §3.2 音色决策 |
| 失败处理 | `sh()` 抛 `BuildError`，整条流水线停止 |

### 换音色

```bash
python build.py <plan.json> --dataset <目录> --voice ref:voice_ref.wav   # 主角克隆（首选）
python build.py <plan.json> --dataset <目录> --voice 小棠                 # 题材预设
```

> 音色用途标签 ≠ 语速适合。实测：纪录片 3.75 字/秒（太慢）、
> 小棠 4.69、子言 4.55、谭湘文徐浩伦 6.00（喜剧双人题材显式选用，**非默认**）。

## 3. 下游：剪辑与包装（转交契约）

### 3.1 何时转交

**本引擎完成后**，出现以下需求时转交 Agent导演引擎：

| 需求 | 是否转交 |
|---|---|
| 加片头/片尾/水印 / 多平台封面重制 | ✅ 转交（成片主封面本引擎已做） |
| 多集解说成片合并成一个长片 | ✅ 转交 |
| 精剪节奏、卡点、转场特效 | ✅ 转交 |
| 导出多平台版本（横屏/不同时长） | ✅ 转交 |
| 解说成片本身的配音/混音/字幕 | ❌ 本引擎已做，不转交 |
| 修改某句解说词 | ❌ 改 plan.json 重跑 build.py |

### 3.2 交接物（本引擎产出）

```
<out-dir>/
├── <片名>.mp4            ← 解说成片（1080×1920 / -14 LUFS / 字幕已烧）
└── _work/
    ├── speech/seg*.wav   分段配音（可单独重配）
    ├── raw*.wav          原声切片
    ├── c*.mp4            分段画面
    ├── silent.mp4        无音拼接版
    ├── mixed.mp4         混音后无字幕版
    ├── subs.srt          字幕（utf-8 无 BOM）
    └── plan.json 回写版  含 duration / raw_start / total_sec
```

### 3.3 传给下游的信息

| 信息 | 来源 | 用途 |
|---|---|---|
| 成片 mp4 | `<out-dir>/<片名>.mp4` | 剪辑素材 |
| 字幕 srt | `_work/subs.srt` | 改字幕/换样式（**无需重烧**） |
| 无字幕版 | `_work/mixed.mp4` | 需要换字幕样式或加片头时 |
| 无音版 | `_work/silent.mp4` | 需要重配音频时 |
| 分段配音 | `_work/speech/seg*.wav` | 只需改某句时 |
| plan.json | 回写版 | 知道每段来自哪集哪个时间点 |

### 3.4 下游引擎入口

**Agent导演引擎**（总控，仅本地）
```
C:\Users\Administrator\.workbuddy\skills\Agent导演引擎\SKILL.md
```
- specialties 登记：`post → 导演后期`、`ffmpeg → ffmpeg-advisor`、`voice → 本地配音工坊`
- 覆盖：配音 → 混音 → 剪辑 → 字幕 → 封面 → 质检
- 本地边界：不上传、不发布、不调云端

**导演后期**（专项）
```
C:\Users\Administrator\.workbuddy\skills\导演后期\SKILL.md
```

### 3.5 责任边界（重要）

| 事项 | 本引擎 | 下游引擎 |
|---|---|---|
| 解说配音 | ✅ 负责 | 不重复 |
| 原声切片与 ASR 定位 | ✅ 负责 | 不重复 |
| BGM 选曲与 duck | ✅ 负责 | 不重复 |
| 字幕生成与烧录 | ✅ 负责 | 可重烧/换样式 |
| **音轨长度 == 视频长度** | ✅ **硬校验，不过不交付** | 收到即视为已通过 |
| 响度 -14 LUFS | ✅ 硬校验 | 可再调整 |
| 成片主封面（`make_cover.py` 已做并烧首帧） | ✅ 负责 | 不重复 |
| 片头片尾 / 水印 / 多平台包装 | ❌ 不做 | ✅ 负责 |
| 多片合并/平台适配 | ❌ 不做 | ✅ 负责 |
| 最终发布 | ❌ **永不做** | ❌ 也不做（需用户指令） |

> **本引擎交付的成片，下游可以信任音频链路**（有硬校验背书）。
> 但**画面正确性仍需人工确认**——校验只管音频，管不了画面。

## 4. 旁路：ffmpeg 命令审查

### 何时用

`build.py` 报以下错时，先问 ffmpeg-advisor，不要盲改：

- `Error : Invalid argument`（滤镜语法）
- `No option name near '...'`
- 字幕/滤镜相关的转义问题
- 需要优化编码参数时

### 入口

```
C:\Users\Administrator\.workbuddy\skills\ffmpeg-advisor\SKILL.md
```

四种模式：分镜成片 / 正向创作 / **反向检测（审查已有命令）** / 问答。

### 已知坑（本引擎踩过的，可直接查）

| 报错 | 真因 | 修法 |
|---|---|---|
| `Invalid argument`（混音） | duck 用 `\|` 拼接 | 逗号串联 + `between()` 单引号 |
| `No option name near` | 同上 | 同上 |
| `Invalid argument`（字幕） | 中文路径 + 反斜杠 | ASCII 路径 + 正斜杠 + 转义冒号 |
| `truncated \UXXXXXXXX` | docstring 里的 Windows 路径 | 用 `r"""` |

完整 **97 条**见 `00-pitfalls.md`（P01–P97 连续编号，带顶部速查索引与分类导航）。

## 5. BGM 素材库对接

本引擎的 BGM **不是自己合成的**，来自素材库：

```
D:/Agent引擎/音频素材库/         467 首 BGM + 891 个 SFX（3676 个音频）
```

选曲用 **BGM音效引擎** 的四步流水线：

```bash
# ① 时间轴分析
python ~/.workbuddy/skills/BGM音效引擎/scripts/analyze_video.py --video <成片.mp4> -o timeline.json

# ② 选曲（有口播必须 --no-vocal）
python ~/.workbuddy/skills/BGM音效引擎/scripts/pick_bgm.py --intent "古风 仙侠" --dur 120 --top 6 --no-vocal  # 现行 60–300s；旧 29s 请求已作废

# ③ 决策（见 references/directing.md）
# ④ 铺轨（本引擎 build.py 已内置 duck，只需传 --bgm 路径）
python build.py <plan.json> --dataset <目录> --bgm <曲路径>
```

> 本引擎**只消费选曲结果**（`--bgm` 传路径），不重复实现选曲逻辑。

## 6. 转交检查清单

把成片交给下游前，确认：

- [ ] `build.py` 校验全过（音轨完整 / 无静音 / 响度 -14 ±2，容差以 `output.loudness_tolerance` 为准）
- [ ] **抽帧确认画面正确**（校验只管音频！）
- [ ] 字幕已烧入成片，且 `_work/subs.srt` 可单独取用
- [ ] `_work/mixed.mp4`（无字幕版）存在，供换样式用
- [ ] plan.json 已回写 `duration` / `raw_start` / `total_sec`
- [ ] 已知缺口已告知用户（见 SKILL.md §4.2）
