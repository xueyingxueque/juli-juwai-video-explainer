## 一、★ 为什么必须推倒重来（补丁的代价）

### 实测：三个脚本里各有一份混音逻辑

```
mix_v6.py           ← 混音逻辑第 1 份
series_assemble.py  ← 混音逻辑第 2 份
run_pipeline.py     ← 混音逻辑第 3 份（调用第 1 份）
```

**三份逻辑互相调用、编号体系不一致**：
- `seg00.wav` 是 0-based
- `raw01.wav` 是 1-based

于是「找不到就跳过」，后面段静默没音。

### 补丁 vs 重写

| 做法 | 结果 |
|---|---|
| 继续在 v8 上改 | 改第 3 处、忘改第 2 处、再出第 4 个 bug |
| 归档旧代码，从零写一个文件 | 逻辑只有一份，编号统一，缺文件直接报错 |

**归档位置**：`scripts/_old_patches/`（保留可查，但不再参与运行）

## 二、★ 新实现：`scripts/build.py`（唯一入口）

```bash
python build.py <plan.json> --dataset <素材目录> [--voice 音色] [--bgm 路径]
```

**单文件、6 步、45 秒**：

```
[1/6] 配音              每段清零重建，实时打印语速
[2/6] 原声定位与切片     ASR 定位真实台词时间点
[3/6] 定时长            唯一数据源 = segments
[4/6] 切画面并拼接
[5/6] 混音              解说/原声结构互斥 + BGM duck
[6/6] 烧字幕 + 校验★    不通过不交付
```

### 五条设计原则（每条对应踩过的坑）

| # | 原则 | 对应的坑 |
|---|---|---|
| 1 | **segments 是唯一数据源**，所有时长从它推导 | 时长散落各处 → 改一处漏三处 |
| 2 | **音轨按段号命名并显式校验**，缺一个就报错 | 文件缺失走「跳过」→ 静默没音 |
| 3 | **`amix duration=longest + apad + atrim`** | `duration=first` → 音轨被截到 2 秒 |
| 4 | **解说/原声结构互斥**，不靠音量控制 | 口播翻译原声 → 同一句话说两遍 |
| 5 | **出片前必须核对音轨长度 == 视频长度** | 音轨 2s / 视频 20.5s |

### 校验不通过就不交付

```
[6/6] 烧字幕 + 校验
    视频 20.4s / 音轨 20.32s
    响度 -14.0 LUFS / 峰值 -1.5 dBTP
    扫描 40 个窗口，最低 -40.4 dB
    ✓ 全部校验通过
```

校验项：
- 音轨长度 vs 视频长度（差 > 0.5s 报错）
- 静音窗口（<-50dB 逐窗检查）
- 响度偏离目标 > 1.5 LUFS 报错

**任一不通过 → 抛异常，不产出成片。**

## 三、★★★ 重写时又踩的三个坑（同一类）

### 1. BGM duck 的 `|` 拼接（第 2 次犯）

```python
# ✗ | 被当成滤镜分隔符 → Invalid argument
volume="between(t,0,2):volume=0.2|between(t,2,7):volume=0.06"

# ✓ 逗号串联 + between() 单引号包裹
volume=enable='between(t,0,2)':volume=0.2,volume=enable='between(t,2,7)':volume=0.06
```

**同一个错我犯了两次**（mix_v6 和 build.py），说明「修好一处」不等于「记住规则」。

### 2. TemporaryDirectory 的生命周期陷阱（新踩）

```python
# ✗ ffmpeg 在 with 块内写文件，之后还要读 → with 结束后目录已删
with tempfile.TemporaryDirectory() as td:
    wav = Path(td) / 'a.wav'
    sh([FF, ... str(wav)])
    w = wave.open(str(wav))      # NotADirectoryError!
```

**正解**：中间文件放工作目录 `work/`，不用临时目录。

### 3. amix 的 `|` vs 逗号（同一个坑的两种表现）

- `|` 用于**滤镜之间**的分隔（不能出现在 volume 参数值里）
- `,` 用于**滤镜链内部**

**判定方法**：参数值里要出现分隔符时，必须转义或换分隔符。
