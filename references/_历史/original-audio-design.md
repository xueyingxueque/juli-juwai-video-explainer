# 原片原声设计（v2.6 规划 · 当前为空白）

> ⚠️ **文档状态校准（2026-10-14）**
>
> 本文写于 v2.6 规划期，开头称"引擎完全没有这个能力"——**该描述已过时**。
>
> **当前实现（以 `scripts/build.py` 为准）**：
> - plan 的 `segments[].raw = 1` 且 `text` 留空 → **纯原声段**（与解说结构互斥）
> - `cut_raw()` 用 **ASR 定位真实台词时间点**后切片（字幕时间 ≠ 语音时间）
> - BGM 按段 duck（解说段 0.20 / 原声段 0.06）
> - 原片环境音**不混入**（实测底噪 -4.3dB 是噪音源）
> - 归属判据：画面说不出但能看出→解说；角色实说且有张力→原声；画外音转述→解说
>
> **本文剩余价值**：四层响度矩阵、原声五种戏剧功能（炸点/情绪/氛围/反应/切句）、
> 版权规避配额（单段≤5s、总占比≤25%、连续≤8s）——这些是**设计思路**，部分尚未实现。
>
> 详见 `SKILL.md` §3.4「原声与 BGM」。

## 一、为什么必须做

### 1.1 调研结论：原声是爆款标配，不是可选项

来源：《用AI做第一人称电影解说》等实操教程明确做法：

> **「保留角色原声」**：剪辑时对「经典对白片段」（如《阿甘正传》
> "Life is like a box of chocolates"），右键「分离音频」，**保留原声音频，
> 叠加在解说音频下方（音量调至 30%-40%），增强真实感。**

关键参数（可直接进配置）：
- 配音音量 **80%**，角色原声音量 **30%-40%**
- 经典对白片段时长 **5-10 秒**
- 镜头时长控制 **5-10 秒**，一句话配一个画面

### 1.2 原声的三种作用

| 作用 | 说明 | 真实爆款案例 |
|---|---|---|
| **证据** | 让观众亲耳听到关键台词，不是解说说了算 | 各类"听见原声才震撼"的转折点 |
| **代入** | 观众熟悉的演员/台词原声，唤起记忆 | 《让子弹飞》开场用姜文"站着挣钱" |
| **留白** | 解说停下来，让原声自己说话 | 名场面常只用原声 + 字幕，不叠解说 |

### 1.3 对短剧的意义更大

短剧的原声价值比电影更高——短剧观众大量是**追更复看**，
经典台词原声就是记忆锚点。而且**版权上更安全**：原声是评论性引用，
比搬运画面片段风险低（前提：不连续搬运）。

## 二、技术可行性（已实测）

### 2.1 精确时间戳：**已验证可行**

用 faster-whisper（已有）转写原片音频：

```
片段数: 106
[  0.00-  2.40] 为了当妻子合送竞争参与极团合伙人
[  2.40-  4.18] 我花了一个月研发出了一桌贵兵产
[  5.10-  6.72] 他却让刚来公司的海规同时
[  6.72-  8.32] 顶替我主处的身份去潜艇
```

**每个对白都有 `[start-end]` 秒级时间戳 + 字级时间戳**，
可直接用 ffmpeg `atrim` 精确切出原声片段。**不需要额外工具。**

### 2.2 配置冲突（必须先解决）

当前 `config/engine.json`：

```json
"compliance": {
  "max_continuous_original_sec": 2.5,   ← ★ 与原声需求冲突
  "commentary_ratio_min": 0.6
}
```

**问题**：`max_continuous_original_sec: 2.5` 是为"防搬运连续画面"设的。
但爆款要放 **5-10 秒经典台词原声**——按现规则会直接判违规。

**必须区分两类内容**（这是本节最关键的改动）：

| 类型 | 判定 | 上限 |
|---|---|---|
| **连续原画面**（无声/背景音） | 防搬运 | 保持 2.5 秒 |
| **原声台词引用**（有明确台词内容） | 评论性引用 | 建议 ≤ 8 秒 |

**建议配置**：
```json
"compliance": {
  "max_continuous_original_sec": 2.5,
  "max_original_audio_sec": 8.0,          // 新增：原声台词上限
  "original_audio_must_be_dialogue": true, // 新增：必须是清晰对白，非环境音
  "commentary_ratio_min": 0.55,            // 原声占用需从解说占比中豁免
  "original_audio_note": "原声属评论性引用，与搬运画面不同；但商用前须自行确认素材授权"
}
```

## 三、解说稿里怎么标（v2.6 要实现）

### 3.1 段落任务链要加一个新位置

现有 10 段：`hook → setup → setup2 → rising → core → climax → climax2 → twist → aftertaste → cta`

**新增 `raw` 段（原声段）**：

```
hook      身份+反差
setup     抛出外部目标
setup2    立不为人知的特质（埋线）
rising    交代怎么碰上
core      交代怎么应对/合作
climax    第一个名场面（解说）
raw       ★ 原声台词（解说停，让原声说）
climax2   第二个名场面（解说）
twist     反转/收回伏笔
aftertaste 升华
cta       互动
```

### 3.2 每行输出格式（扩展现有 lines 结构）

```json
{
  "lines": [
    {
      "text": "注意看，小帅被妻子逼退学打工",
      "block": "hook",
      "tone": "exaggerated",
      "evidence_ids": ["E015"],
      "audio": null
    },
    {
      "text": null,
      "block": "raw",
      "raw_audio": {
        "start": 62.4,
        "end": 68.1,
        "duration": 5.7,
        "dialogue": "我当初嫁给你都没考虑过这些",
        "volume_ratio": 0.35,
        "reason": "这是她亲口说出当年隐忍的实情，比解说更有说服力",
        "evidence_id": "E006"
      }
    },
    {
      "text": "这句话之后，他做了一个决定",
      "block": "core",
      "tone": "slower",
      "evidence_ids": ["E018"]
    }
  ]
}
```

**关键字段**：
| 字段 | 说明 |
|---|---|
| `text: null` | 原声段没有口播，**解说停** |
| `start/end` | 原片时间戳（秒） |
| `dialogue` | 这段台词原文（供字幕用） |
| `volume_ratio` | 原声音量，**默认 0.35**（配音 0.8） |
| `reason` | **为什么这里用原声**（必填，防止滥用） |

### 3.3 挑选原声的判据

**不是每句都能配原声**。必须满足至少一条：

| 判据 | 说明 |
|---|---|
| **台词本身有张力** | 「我当初嫁给你都没」比解说转述有力 |
| **画面与台词有反差** | 画面在哭，台词在忍 |
| **是转折/爆点** | 「我从没拿辍学当把柄」这种 |
| **观众已知** | 追更观众听过原片，原声能唤记忆 |

**禁止**：拿无信息量的环境音（风声、餐具声）充数。

## 四、S4 装配怎么落地（ffmpeg 已可实现）

### 4.1 音频轨道

```
轨道1（主）：解说配音        volume 0.8
轨道2（辅）：原声片段        volume 0.35    ← 新增
轨道3：BGM               volume 按情绪曲线
```

### 4.2 核心命令

```bash
# 切原声片段
ffmpeg -i source.mp4 -ss 62.4 -t 5.7 -vn -ac 1 -ar 44100 raw.wav

# 解说段（原声段留空）
ffmpeg -i narr.wav -af "volume=1.0" narr_norm.wav

# 混音：解说 + 原声按时间轴对齐
ffmpeg -i final_video.mp4 -i narr_norm.wav -i raw.wav \
  -filter_complex "[1:a]volume=0.8[a1];[2:a]volume=0.35[a2];\
                  [0:a][a1]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" out.mp4
```

### 4.3 响度归一

原声片段与 TTS 配音**响度不一致**（原声是现场录音，TTS 是合成音）。
必须分别归一到同一 LUFS，否则叠加时会一高一低：

```bash
# 分别归一
loudnorm=I=-14:TP=-1.5 narr.wav
loudnorm=I=-14:TP=-1.5 raw.wav
```

**这是原声最容易翻车的地方**，必须做。

## 五、质检要加什么

| 门 | 判据 |
|---|---|
| **原声时长门** | 单段原声 ≤ 8 秒，总原声占比 ≤ 20% |
| **原声必要性门** | `reason` 为空 → FAIL（防滥用） |
| **原声内容门** | `dialogue` 必须非空且 ≥ 4 字（不能是环境音） |
| **响度一致性门** | 原声与配音 LUFS 差 ≤ 2 LU |
| **字幕门** | 原声段必须有字幕（观众听不懂会走） |

### 步 1：合规配置已区分两类内容 ✅

`config/engine.json` → `compliance`：
```json

"max_original_audio_sec": 8.0,           // 原声台词引用（评论性引用）
```

### 步 2：对白时间戳清单已产出 ✅

新增 `scripts/dialogue_map.py`，实测 147.2s 素材：

```
片段 108 条，时长 147.2s
可做原声 97 条（占比 90%）

最适合放原声的 TOP6：
  D040 [ 56.86- 58.64] score=1.00  我要退学去打工
  D005 [  6.72-  8.32] score=0.87  顶替我主处的身份去潜艇
  D011 [ 14.98- 16.66] score=0.87  但这次我直接地交了辞职报告
  D019 [ 29.72- 30.84] score=0.87  我顶替神出的称号
  D042 [ 62.30- 63.72] score=0.87  然后我就去办了退学手续
  D075 [108.94-109.72] score=0.87  我心里冷笑
```

**TOP1「我要退学去打工」正是这个故事最有张力的一句** —— 时间戳 56.86-58.64。

`quote_score` 判据：长度适中(5-22字) + 含第一人称 + 含张力词（顶替/羞辱/退学/金牌…）。

**全链路已通**：原片 → ASR 时间戳 → 筛原声候选 → ffmpeg 精确切片。
