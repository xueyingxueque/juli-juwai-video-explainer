## 一、调研结论（五路情报浓缩）

### 1.1 平台原创度治理（今年最大变量，决定账号生死）

| 情报源 | 核心结论 |
|---|---|
| 抖音集团短剧版权中心《内容原创度建议公告》（2026-03） | 同质化素材多账号分发/搬运/遮挡水印/外站素材直接发布 → **原创度不足治理**（限流+账号降权+功能限制） |
| 澎湃/DataEye（2026） | 2026 Q1 全行业 AI 微短剧占比 >95%，平台审核持续加码；「模板微调生成上百条」已失效，必须「真原创、差异化」 |
| GitHub 抖音去重机制研究（2026-02） | **三层指纹**：① 视觉：关键帧 pHash（32×32 DCT 低频，汉明距离），2025 已进化到 **AI 语义级**（CNN 核心像素排列特征，镜像都能识别）；② 音频：MFCC 频谱指纹（识别相同配音/BGM/变速）；③ 文本：OCR+ASR+NLP 语义相似度（识别相同文案，**即使换人说**） |
| conbersa/renderio（2026） | 有效对抗：视觉需**组合变换**（4+px 裁剪+噪声+几何变换+抽帧改帧序+变速，单一手段无效）；音频需 pitch shift ≥0.5% 或 time stretch；文本需真原创；元数据 `-map_metadata -1` 剥离；**24-48 小时窗口内同平台对比最严** |

### 1.3 内容侧爆款公式（100+ 爆款拆解）

- 黄金 3 秒钩子（直接冲突/倒叙/身份反差），**0-10 秒交代核心矛盾+人物关系+主角目标**

- 痛点前置（完播 +42%）；结尾卡死强钩子催更
- 人设记忆点（方言/固定称呼/口头禅）→ **第一人称+音色克隆正是人设基建**
- 行业基数：日均 500 万条、完播率 <15%、73% 套三幕式模板 → **差异化就是机会**

## 二、差距分析（诚实版）

| 维度 | 业界 2026-10 水位 | 我们现状（v3.5.0） | 判定 |
|---|---|---|---|
| 音频指纹对抗 | AI 原创解说音（非原声） | ✅ 100% 原创 TTS 音轨 | **天然占优** |
| 文本指纹对抗 | 原创文案 | ✅ 原创解说词+第一人称 | **天然占优** |
| 视觉指纹对抗 | 组合变换+帧级重构标配 | ❌ 画面 100% 原片帧序（仅按解说重排镜头） | **★ 致命软肋** |
| 原字幕处理 | 模糊成标配 | ❌ 候选未做（双字幕叠加） | 高 |
| 原创度自检 | 发布前 pHash/声纹自检 | ❌ 无（质检不查平台指纹） | 高 |
| 音色 | 克隆+自动选色 | ✅ v3.5 刚落地 | 追平 |
| 文案工程 | 钩子公式+情绪词库 | ✅ 第一人称+lint 刚落地 | 追平 |
| 质检深度 | 合规代理（C2PA/法案） | ✅ 硬门四道+软门+分档 | **占优** |
| 证据链 | 无（工具不看剧情） | ✅ VLM 逐帧+ASR 锚定+validate | **显著占优** |
| 编排架构 | 多代理+Judge 闭环 | ⚠️ 单链 build+人工返修 | 中 |
| 批量产线 | 队列化批量 | ⚠️ 单部单跑（三剧连产靠人肉串） | 中 |
| 授权合规 | 授权通道 | ⚠️ 灰色素材（网盘） | 中（风险） |

**一句话结论**：我们的「证据链+质检+原创音/文案」是业界工具没有的深水位；**唯一生死级短板是视觉帧序层未做重构**——同剧多人做解说时选镜逻辑趋同 → pHash 相似 → 同质化限流。v3.6 必须补这块盾牌。

## 三、进化路线图（三版递进，全部适配 WorkBuddy）

### v3.6「原创盾牌」——目标：过审从运气变工程（2-3 天，最高优先）

> **2026-10-22 落地状态**：`scripts/anti_dup.py` 已实现「非几何子集」——色相微旋转
> （hue=2°/4°）+ 对比度饱和度微调 + 轻时域噪点（alls=2/4）+ 元数据剥离（-map_metadata -1），
> 音频流 `-c:a copy` 不碰响度，输出前后核对音画时长（>0.3s 拒绝交付）。
> **形态是独立可选后处理，没有动 build.py 主结构**（遵守「未验证不改 build.py」纪律；
> yjfxx D1 实测待补视觉确认）。
> **几何变换（缩放/裁切/镜像/微变速）明确延期**：短剧字幕位置不一，任何裁剪都可能切字幕
> 安全区或糊人脸——需先做 safe-zone 感知（按 shotmap 字幕坐标避让）才敢上，列入下轮。
> 字幕模糊 / uniqueness 自检门未动。

| 模块 | 内容 | 落点 |
|---|---|---|
| **画面重构层** | build.py 新增 `--anti-dup <seed>`：按 segment 派生确定性随机种子，组合施加——缩放 100-104% + 4-8px 裁切 + 镜像（≤30% 段）+ 微变速 0.96-1.04 + 帧抖动（每段 ±2 帧重采样）+ 轻噪声 alls=4 + 按段扫光（10% 段）。**每种变换强度低于「看得难受」阈值，组合后帧序/像素结构语义级变化** | `scripts/build.py` vf 链追加（不动主结构，滤镜串尾部挂 anti-dup 组） |
| **原字幕模糊** | spec 段加 `blur:[y0,y1]`（默认按平台 safe_bottom 推算）；ffmpeg `boxblur` 区域模糊原字幕，解说字幕改放安全区上沿，双叠消除 | build.py 切画面后、烧字幕前 |
| **原创度自检门** | quality_gate 新增 `hard/uniqueness`：抽成片 10 帧算 dHash，与「原片对应时间段帧」算汉明距离；同片段距离 <10 的段占比 >30% → FAIL 并指出段落。**用平台同款 pHash 武器自卫** | `scripts/quality_gate.py` + 新 `uniqueness.py` |
| **元数据剥离** | 输出统一 `-map_metadata -1 -movflags +faststart` | build.py 输出参数（anti_dup.py 已先行实现，build.py 集成待定） |
| **封面差异化** | 同剧多部封面自动换底图候选+排版变体（seed 派生） | 封面脚本 |

**验收**：金条/渔家各重建 1 部 → uniqueness 门 PASS → 双字幕叠加消除（抽帧）→ 观感无损（变换阈值不穿帮）。

### v4.0「双 Agent 闭环」——目标：质量问题定向返修，不再全重置（1-2 周）

| 模块 | 内容 | WorkBuddy 适配 |
|---|---|---|
| **角色卡锁定** | S2 产出 `characters.json`（主角/反派外貌锚点+关系），跨集/跨片一致性校验（VLM 比对） | references/ + S2 脚本 |
| **Judge 返修环** | quality_gate 失败分类（technical/subtitle/copyright/uniqueness/semantic）→ 返修策略表：subtitle 失败→改 ASS 坐标；uniqueness 失败→该段 anti-dup 种子重摇；copyright→削原声；**定向修单点，不重启全链**（Google Co-Director 闭环的本土简化版） | 新 `scripts/repair_advisor.py`（读 qc.json 出返修处方） |
| **选镜差异化引擎** | 同剧第 2/3 部自动避开第 1 部已用镜头（shotmap 谱系），优先未用高光帧——**结构层面根治同质化**（比纯帧级变换更语义级） | `series_plan.py` 增加谱系避重 |
| **钩子公式入库** | S3 接入爆款公式库（黄金 3 秒/15 秒锚点/结尾卡死），lint 加「钩子密度」检查（每 20-30s 一个刺激点） | `references/hook-patterns.json` + lint |

**验收**：同剧三部并产，两两视觉指纹汉明距离均值 >20（pHash 层判定不同内容）；返修环实测：注入 3 类故障→定向修复不过夜。

### v4.5「工业化产线」——目标：日产 N 部，人只看数据（1-2 月，持续迭代）

| 模块 | 内容 | WorkBuddy 适配 |
|---|---|---|
| **批量调度器** | 一批 N 部剧：队列化跑（ingest→plan→build→qc），单部失败不堵队列，失败进重试区 | skill 主流程 + `--batch` 模式 |
| **定时产线** | automation 每日触发「今日产线」：跑 N 部+汇总报告（成功/失败/质检分档） | `automation_update` recurring |
| **数据回流** | 发布后回采播放/完播数据（人工导出或连接器）→ 钩子库/选剧模型自进化（hermes-learning-loop 模式） | 新 skill 或 references 数据文件 |
| **授权合规位** | 素材准入检查（授权书/平台二创计划白名单），未授权素材标记风险档 | 素材预检门扩展 |
| **分发一环** | 成片+封面+文案 → 平台分发（先人工确认后自动，遵守 AI 辅助创作勾选） | 自动发布平台引擎（已有 skill 转交） |

**验收**：一条指令「开始今天的产线」→ 无人值守产 3 部 → 早报汇总；返修率 <20%。

## 五、风险与纪律

- anti-dup 变换强度上限纪律：**观众无感优先**——阈值超标（缩放 >8%/噪声可见/变速 >10%）视为 bug 不是参数
- uniqueness 门是「自卫检测」不是「对抗保证」：平台算法黑盒且月变，门过 ≠ 绝对安全，仍需人工抽帧+多版本分发策略
- 授权合规：v4.5 前不接未授权剧集的商业分发；解说二创走平台扶持类别，发布勾选 AI 辅助创作
- 每版落地遵守既有纪律：改 build.py 不动主结构（滤镜挂尾部）；新脚本先小样本验证再上生产链
