## 1. 依据与边界

| 依据 | 生效 | 对本引擎的要求 |
|---|---|---|
| 《人工智能生成合成内容标识办法》第四条 | 2025-09-01 | 视频在**起始画面和播放周边**显式标识；末尾 / 中间可选 |
| 同上第五 / 六条 | 2025-09-01 | 文件元数据隐式标识：生成属性 / 服务提供者名称或编码 / 内容编号；传播侧另含平台名称或编码 |
| 《微短剧发展管理办法》（总局令第 16 号）第 34 条 | 2026-09-01 | 每集明显位置提示标识 |
| 广电总局低俗化同质化专项治理 | 2026-11-06 起 | 治理「改头换面、反复播出」「推荐同质化」→ 支撑 F13 跨集去重 |
| 中央网信办 6 类必选标签 | 2026 | 内容标注为发布必经环节 |

★ **v6.0.0 勘误**：旧版把「片头前 3 秒 / 封面 / 简介」写成法规要求，实为二手平台运营文
口径，无权威来源，且与「显式持续 ≥2 秒」实现范例冲突。已改为法规原文落位 + 发布侧三处；
强标参数与 6 类标签逐字表述列入存疑清单（06 号文档 §8），**不进质检硬门**。

本引擎定位是**评论式解说**（解说配音与二创画面由 AI 生成，剧情素材来自原片），
生产零联网，不代替发布环节的平台勾选与人工审核；司法上须避免对原片形成「实质性替代」。

## 2. 显式标识与隐式标识

| 类型 | 内容 | 谁负责 |
|---|---|---|
| 显式（视频） | `compliance_policy.ai_label` 出现在**起始画面 + 播放周边** | 物料由 `scripts/publish_kit.py` 生成；落位由发布环节执行，引擎不自动改画面 |
| 显式（发布侧） | 封面文案 / 发布简介 / 发布页必选标签 | 同上，物料可直接复制 |
| 隐式 | 视频元数据**标准键** `comment`（生成主体 / 版本 / 作品编号 / AI 参与比例 / 生成时间）与 `description` | **`scripts/produce.py` 的 deliver 步强制调用** `compliance.py stamp --apply`（幂等 + 写后复核） |

强标实现范例（媒体转述，**存疑**）：显式文字高度 ≥ 画面最短边 5%（1080×1920 → 约 54px）、
持续 ≥2s。只作发布物料提示，不作硬门。

实测：进化前的 6 支成片 `format_tags` 只有 `encoder`，零 AIGC 标识。
⚠️ MP4 只接受 `comment/description/title` 等标准键，任意键会被静默丢弃（P91），
因此标识必须落在标准键上并做写后复核 —— 唯一判据是 `compliance.has_aigc_tag()`（P92）。

## 3. 发布页必选标签

6 类：含有虚构演绎内容 / 含有AI生成内容 / 含有营销信息 / 内容为转载 /
内容为个人观点 / 无需标注。发布须选一项；本引擎产出通常落「含有AI生成内容」，
视内容叠加「含有虚构演绎内容」「内容为转载」。
**引擎不自动勾选（F7）**；以平台实际标签为准。

## 4. 预检维度

`compliance.py check` 输出 P0/P1/P2 三级结构化报告
（`level / category / description / recommendation`）：

- **P0** 内容安全敏感词 → `ok=false`
- **P1** 营销字样、广告法绝对化用语、平台导流词、封面主标超 16 字
- **P2** AI 显式标识、发布页必选标签、隐式标识清单、音色授权、双层字幕提示（P87）

判据经验：中文序数（「第一集」「荒界第一天」）**不是**广告法绝对化用语，
预检会先剔除这类语境再匹配，避免误报（MW1 实测修过两轮）。

## 5. 命令与用法

```bash
python scripts/compliance.py check <任务> <ep> <gencfg.json>         # 只读
python scripts/compliance.py provenance <任务> <ep>                   # 溯源清单
python scripts/compliance.py stamp <video> --task <任务> --ep 1        # dry-run
python scripts/compliance.py stamp <video> --task <任务> --ep 1 --apply # 写入
python scripts/publish_kit.py --task <任务> --ep 1 --video <封面版.mp4> --prefix T1
```

`stamp` 安全设计：**幂等**（已标识跳过）→ 写临时文件 → ffprobe 复核确含 AIGC →
原片留 `.pre-aigc` 备份 → 原子替换。任一步失败删除临时文件、不动原片（F10）。
6 支历史成片已于 2026-11-11 经用户确认后批量补标；**新产出的成片由 deliver 步自动补标**，
不再依赖人工。

## 6. 生成链路留痕

`provenance-<ep>.json` 记录 spec / ev / plan / v37 / state / precheck / qc 的
sha256 与字节数、引擎与技能版本、ASR/TTS/VLM 模型、时长与去重策略快照。
`publish_kit.py` 会核对它是否存在并给出补生成命令。

## 7. 已知限制

- 不自动擦除原片烧录字幕（P87）；ASS 底栏只是压盖，交付前须抽帧。
  **真擦除经二次调研明确不采纳**（合规风险 + 几十分钟/条 + 帧间闪烁），见 06 号文档 §3。
- 隐式标识的**哈希校验值**当前未写入，如实列为缺口，不伪装已合规。
- 不自动取得音色授权；主角音色克隆前须确认素材授权范围，无授权改用题材预设音色。
- 不代替平台侧的 AI 创作声明勾选、必选标签、备案与人工审核。
- 词库是工程预警，不是完整法律词表；平台规则变化时应更新 `compliance_policy`。
- 强标参数、6 类标签逐字表述、完播率类数字均为二手 / 存疑，**禁止写进硬门**。
